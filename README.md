# Primera pre-entrega de JavaScript 

Simulador interactivo de compras para una comiquería realizado para el curso de JavaScript.

## ¿Qué hace el script?


La idea es hacer un simulador sencillo de compra para una comiquería. El usuario puede ingresar su nombre, elegir un cómic, indicar la cantidad que quiere comprar y el precio de cada unidad.



Contenidos que usé
Variables con let y const.
prompt, alert y confirm.
Conversión de datos con parseInt y parseFloat.
Condicionales para validar los datos.
Un bucle while para repetir la compra.
Mensajes en la consola con console.log.
