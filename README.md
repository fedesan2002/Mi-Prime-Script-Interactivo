# Primera Pre-Entrega - JavaScript

Simulador interactivo de compras para una comiquería realizado para el curso de JavaScript.

## ¿Qué hace el script?

1. Da la bienvenida al usuario.
2. Solicita el nombre del cliente y del cómic a comprar.
3. Pide cantidad y precio unitario, convirtiendo los datos a números (`parseInt` y `parseFloat`).
4. Valida que los datos ingresados sean correctos.
5. Calcula el costo total y muestra el resultado en pantalla (`alert`) y en la consola (`console.log`).
6. Permite repetir el proceso mediante un bucle `while` usando `confirm`.
